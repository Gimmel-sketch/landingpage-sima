Metode Mamdani · Centroid

Sistem Evaluasi Fuzzy

Menilai performa akademik mahasiswa secara gradual dari tiga variabel input, tanpa lompatan nilai yang drastis.

Variabel Input

Rata-rata NilaiRendah · Sedang · Tinggi
IPKRendah · Sedang · Tinggi
SKS LulusSedikit · Cukup · Banyak

Variabel Output

Performa Akademik: Kurang, Cukup, Baik, Sangat Baik — dihitung melalui defuzzifikasi centroid.

Fungsi Keanggotaan (IPK)

Ilustrasi kurva segitiga/trapesium untuk derajat keanggotaan IPK terhadap tiga himpunan fuzzy.
